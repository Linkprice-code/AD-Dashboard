    GFA 데이터 업로드

    GFA는 네이버 광고 API 연동 전이라 원시 데이터를 CSV 파일로 직접 업로드합니다. 아래 컬럼명을 첫 줄(헤더)에 그대로 포함한 CSV 파일을 업로드해주세요. 컬럼 순서는 상관없습니다.

    date, campaign, ad_group, product, impressions, clicks, cost, conversions, revenue

    예시 한 줄: 2026-08-01,여름신상프로모션,배너그룹A,ADVoost,15200,320,540000,18,3200000

    CSV 템플릿 다운로드

    같은 날짜(date)로 다시 업로드하면, 그 날짜의 기존 GFA 데이터는 새 데이터로 교체됩니다 (중복 누적 방지).
